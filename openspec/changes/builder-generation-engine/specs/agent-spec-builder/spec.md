# Spec Delta

## ADDED Requirements

### Requirement: Generation technique is selectable
The build's generation step SHALL support two techniques — a single-shot technique (one model call
emits the whole spec) and the Embabel NL compiler — selected per build, with the single-shot
technique as the default. Both techniques SHALL produce the shared agent-spec format so that
validation, evaluation, the security gate, lifecycle, and publish are identical regardless of the
technique used.

#### Scenario: Default is single-shot
- **WHEN** a build is run without specifying a generation technique
- **THEN** the description is generated by the single-shot technique

#### Scenario: Embabel technique requested
- **WHEN** a build is run with the embabel technique
- **THEN** the description is compiled by the Embabel NL compiler

#### Scenario: Technique does not change the pipeline
- **WHEN** either technique produces a draft
- **THEN** the draft is the shared agent-spec format and the downstream stages run unchanged
